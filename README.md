# Vestrata
Vestrata is an AI &amp; ML-powered investment analysis platform for US rental investors. It gathers pricing, rent, tax, insurance, mortgage, and state-rule data, predicts rent/value and risk via ML, and calculates cash flow, cap rate, CoC, DSCR and profit — then AI explains it in plain English. Built as a modular monolith (FastAPI, React, PostgreSQL).
